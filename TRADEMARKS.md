# Trademarks

The GPL covers Escale's code. It does not cover the name **Escale**, the Escale
mark or the app icon: these belong to Kelvin Dupont. This policy says how you
may use them, so that people always know which browser comes from this
project.

## Without asking

- Talk and write about Escale, review it, show screenshots.
- Say what your work is: "a fork of Escale", "based on Escale", "works with
  Escale".
- Redistribute the official builds unchanged.
- Build Escale from source for yourself, under its own name.

## Not without permission

- Publish a modified build under the name Escale, or with its mark or icon.
- Use a name or logo that could be mistaken for Escale's.
- Suggest that your project or product is made or endorsed by Escale.

## Publishing a fork

Give it its own name and icon, and point it away from Escale's services so it
never reaches Escale's users or their data:

- bundle identifier (`com.kndpt.escale`),
- update feed (`escalebrowser.com/appcast.json`),
- repository used for feedback and release pages,
- GitHub App client ID.

[AGENTS.md](AGENTS.md#identity) lists the files that hold each of these.

## Questions

For anything else, open an issue before you publish.
